# Chocolate Sales Analysis 🍫📊

A Python-based data analysis project focused on exploring and analyzing chocolate sales data to identify sales trends, top-performing products, and business insights.

### 🛠️ Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 📊 Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales and product performance analysis
- Trend identification
- Data visualization

The project demonstrates practical skills in **data cleaning, exploratory analysis, visualization, and extracting insights from real-world sales data**.Analysis of dataset related to chocolate companies
